# ADR-0001: 프로토타입과 실제 제품 저장소 경계

- 상태: Accepted
- 날짜: 2026-09-06

## 맥락

Next.js UI 프로토타입은 화면 흐름, Kakao Maps 연결과 사용성을 빠르게 검증하기 위해 Mock reducer와 임시 시나리오 라우트를 사용했다. 이를 그대로 제품으로 발전시키면 임시 상태 모델과 실제 서버 경계가 섞이고 초기 커밋의 의미가 흐려진다.

## 결정

- 기존 코드는 `gatgaga-prototype` 폴더에 참고 자료로 보존한다.
- 실제 제품은 새 `gatgaga` Git 저장소에서 시작한다.
- 확정 문서, Eucalyptus Sage 토큰과 검증된 UI 패턴만 선별 이식한다.
- Mock reducer, `/start` 같은 시나리오 라우트와 프로토타입 전용 데이터는 이식하지 않는다.

## 결과

- 제품 저장소의 커밋과 아키텍처 결정을 처음부터 설명할 수 있다.
- 프로토타입과 제품이 잠시 다를 수 있으므로 PRD·사용자 플로우·화면 명세를 우선 기준으로 사용한다.
- 검증된 UI를 다시 구현하는 비용이 조금 생기지만 임시 구조를 장기 유지하는 비용을 피한다.
