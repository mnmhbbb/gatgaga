## 준비

1. AI가 로컬 PostgreSQL·앱·브라우저 연결 상태를 확인한다. 실행이 필요하면 저장소에서 `nvm use 24.18.1`, `pnpm db:up`, `pnpm dev`를 사용하고 터미널에 표시된 앱 주소로 접속한다. 기존 `.env`의 Kakao/인증 설정을 사용한다.
2. 계정 A의 로그인이 필요하면 사용자가 직접 Kakao 로그인한 뒤 AI가 이어받아 A가 활성 멤버인 테스트 공간을 연다. 테스트 데이터가 실제 저장되며 제거 UI는 아직 없으므로 이름에 `QA-날짜-순번`을 붙인다.
3. 검색 0건용 고유 문자열(예: `QA-직접등록-20261003-01-없는장소`)과 실제로 아는 주소, 근처 장소명을 준비한다. Kakao 결과는 변할 수 있으므로 0건이 아니면 다른 고유 문자열을 사용한다.
4. 기본 검증은 일반 브라우저에서 수행하고 MP-11은 폭 360px에서도 반복한다. 지원 검증의 Offline/차단 설정은 각 케이스 후 해제한다.

## 지원 검증

AI가 도구 지원과 로컬 테스트 상태를 확인해 준비·실행한다. 재현이 안 되면 통과로 적지 않고 원인과 관찰값·필요한 도움을 남긴다. 일반 UI로 준비할 수 없는 DB 상태를 만들기 위해 사용자가 임의로 SQL을 실행할 필요는 없다.
